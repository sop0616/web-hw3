- 사이트 주소 : https://sop0616.github.io/web-hw3/
- 출발점 : 내 #1, #2 과제
- 자료 출처 : TMDB, KOBIS (기존 자료 기준일 2026-10-25)

| 요구사항 | 상태 | 메모 |
|---|---|---|
| 렌더링 | 일부 | 영화 10편, 일부 정보 미확인 |
| 검색 | 구현함 | 제목 검색 |
| 정렬 | 구현함 | 평점, 연도, 제목 |
| 필터 | 구현함 | getView |
| 찜 | 구현함 | localStorage |
| 빈 결과 | 구현함 | 안내 문구 |
| 상세 보기 | 일부 | 일부 데이터 미확인 |
| 이벤트 및 콘솔 | 일부 | 인라인 이벤트 없음, 브라우저 검증 필요 |
| 보너스 | 일부 | 화면 모드 전환, 실시간 API 미구현 |

## 구현 과정의 어려움과 해결 방법
- 검색과 필터 및 정렬을 getView 함수로 통합했다.
- 찜 상태를 localStorage로 저장하도록 구현했다.
- 포스터가 없는 영화에는 제목 첫 글자를 표시하도록 구현했다.

## 참고 자료
기존 실습과제 파일, 과제 안내문, TMDB, KOBIS.
